# Axiom Shield: Open Source AI Privacy Extension & Landing Page 🛡️

The official landing page for **Axiom Shield**, a privacy-first browser extension designed to protect sensitive data and prevent legal liability during AI sessions.

![Axiom Shield Banner](https://shield.aimagine.in/og-image.jpg) *(Placeholder link, update after deployment)*

## 🚀 Overview

Axiom Shield provides a safety layer for ChatGPT, Gemini, Claude, and other AI platforms. This landing page is built with **React**, **Vite**, and **Tailwind CSS**, featuring high-fidelity animations and an interactive real-time redaction demo.

### Key Features of the Landing Page
- **Interactive PII Demo**: Real-time simulation of PII redaction and liability warnings synced with the extension's core logic.
- **Modern UI/UX**: Dark-themed, premium design with fade-in scroll animations using Intersection Observer.
- **Legal Transparency**: Dedicated Privacy Policy and Terms of Service pages.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewports.
- **SEO Optimized**: Pre-configured meta tags for search engines and social sharing.

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **Animations**: CSS Keyframes + Intersection Observer API

## 🏃 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/productdeveloper/Axiom-Shield.git
   cd Axiom-Shield
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

### Building for Production

To create a production-ready build (outputs to the `dist/` directory):
```bash
npm run build
```

## 🛡️ Security & Privacy

This landing page, like the Axiom Shield extension itself, is designed with privacy in mind:
- **Zero Tracking**: No Google Analytics or third-party tracking pixels.
- **Client-Side Demo**: All text processed in the interactive demo stays local to the user's browser.
